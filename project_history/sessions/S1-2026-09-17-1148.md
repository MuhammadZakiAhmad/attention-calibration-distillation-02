**Lessons learned**:
- ProofWriter's `proofsWithIntermediates` is the right granularity for per-question proofs; the theory-level `proofDetails` aggregates every derivable fact across all questions and cannot identify which chain belongs to the asked question.
- **Silent-wrong is the real hazard in this codebase.** The parser bug that dropped rule text still produced output that validated correctly against the question — it was only found by reading rendered output. Any change to the renderer must be re-validated by eye on samples, not just by assertion-passing.
- Testing `classify` against synthetic generations *before* any GPU work caught a `KeyError` that would otherwise have appeared in Colab after the expensive generation stage. Cheap synthetic end-to-end tests are worth writing before the expensive real run.
- Write the resume check before loading the model. On Colab, a model load is minutes; discovering there was nothing to do after paying it is pure waste.
- **Grepping `pool.jsonl` for answer counts is ambiguous.** The renderer's prose contains lowercase "false" on every False-answer record, so naive case-insensitive search double-counts False. Always count the field (`grep -c '"gold_answer": "False"'`), never the bare word.
